Часті питання

Що таке Second Visuals?

Це лаунчер і візуальний Fabric-мод для Minecraft Java Edition. Він робить гру красивішою: освітлення, частинки, анімації, новий інтерфейс.

Які версії Minecraft підтримуються?

Актуальні версії Java Edition з підтримкою Fabric. Точний список з'явиться в лаунчері перед релізом.

Чи потрібна ліцензія Minecraft?

Так, для гри потрібен ліцензійний акаунт Minecraft Java Edition. Лаунчер входить через твій акаунт Microsoft.

Чи можна грати на серверах?

Так. Мод змінює лише те, як гра виглядає у тебе, і не дає переваг у грі. Але завжди перевіряй правила конкретного сервера.

Гра гальмує після встановлення. Що робити?

Обери в лаунчері профіль «Продуктивність» або вимкни окремі ефекти в налаштуваннях мода. Якщо не допомогло — напиши нам і вкажи модель відеокарти.

Коли з'явиться оплата Преміуму?

Ми саме її підключаємо. Новини будуть у нашому Telegram-каналі.
